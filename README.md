# 🤖 AI Resume Analyzer Pro

An AI-powered Resume Analyzer that evaluates resume ATS compatibility, detects technical skills, compares the resume with a selected job role, identifies skill gaps, and provides personalized recommendations.

## 🚀 Features

- 📄 Upload Resume in PDF, DOCX or TXT format
- 📝 Paste resume text directly
- 🎯 Select target job role
- 📊 ATS-style compatibility score
- 🧠 Technical skill detection
- ✅ Matched skills analysis
- ❌ Missing skill identification
- 📋 Resume section completeness check
- 💡 Personalized resume improvement recommendations
- 📱 Responsive and modern UI
- ⚡ Fast analysis without external API dependency

## 🎯 Supported Job Roles

- Data Analyst
- Web Developer
- Python Developer
- Software Developer
- ML Engineer
